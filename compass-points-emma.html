Six-day plan

Each day leans on a different memory principle instead of rereading the same list. Do the day's mode, not all of them.

Learn — first pass

No self-testing here. Read each card once, say the hook out loud, move on.

Recall practice

Say the answer out loud before you reveal it. Grading yourself honestly is what makes this work — struggling terms come back sooner. Pick a chunk in the sidebar to keep it small, or switch scope to the whole set once the chunks feel solid.

Mixed drill

Multiple choice — the wrong options are the terms it's easiest to confuse with the right one. Start scoped to one chunk, then widen to the whole set for real interleaving later in the week.

Test mode

Write every answer before you see any of them, then grade yourself at the end.

Printable study sheet

A clean, no-screen reference for the current term set — read it on paper, no device needed.

Progress

Mastery is tracked per term from your Recall, Drill, and Test grading — not just whether you've looked at it.

Still shaky

Every term — adjust by hand

Felt solid yesterday but shaky today? Knock a term down a level here so it comes back around sooner in Recall and Drill — no need to wait for it to come up on its own.
